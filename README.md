# Singularity

A high-fidelity, real-time relativistic black hole and gravitational lensing simulation built using **Babylon.js** and WebGL raymarching.

## Features
- **Relativistic Raymarching:** Simulates Schwarzschild and rotating Kerr spacetime metrics directly in the fragment shader.
- **Accretion Disk Physics:** Volumetric disk rendering with temperature-based Keplerian shearing, Doppler beaming, and gravitational redshift.
- **Dynamic Camera Views:** Fast transitions between Orbit, Edge, Polar, Disk, and Free camera controls.
- **High-Fidelity Space Environment:** Multi-chromatic nebulae, diffraction spikes on bright stars, atmospheric scintillation (twinkling), and film grain post-processing.
- **Performance Adjustments:** Dynamic hardware resolution scaling, custom raymarching steps, toggleable 60 FPS cap, and power-saving idle throttling.

## Presets Included
- **Realistic Active (Quasar):** Classic active galactic nucleus.
- **Stellar-Mass:** High-speed rotation and blue-shifted hot gas.
- **Sagittarius A*:** Thick, diffuse golden-orange plasma torus mimicking the EHT imaging.
- **Artistic Gold:** Cinematic thin disk styling.
- **Kerr Extreme:** Near-limit black hole spin ($a = 0.99$) with a close-in neon-violet accretion boundary.
- **Sci Grid:** Schwarzschild metric with coordinate grid mapping.
